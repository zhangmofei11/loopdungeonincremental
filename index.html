Game Overview

What is Loop Dungeon?

Loop Dungeon Incremental is an addictive blend of roguelike dungeon crawling and idle incremental mechanics. Each loop through the dungeon brings new challenges, better loot, and permanent upgrades that carry over between runs.

Core Loop

  • 1. Enter the dungeon
  • 2. Fight monsters and collect gold
  • 3. Find equipment and items
  • 4. Die or escape to upgrade
  • 5. Repeat with permanent boosts

Getting Started

  1. 1. Start a new run - Click "Enter Dungeon" to begin your first loop
  2. 2. Move through rooms - Use arrow keys or WASD to navigate the dungeon
  3. 3. Fight monsters - Auto-attack when adjacent, collect gold from fallen enemies
  4. 4. Find equipment - Loot chests and defeated enemies for gear
  5. 5. Upgrade between runs - Spend gold on permanent upgrades at the shop
  6. 6. Die and repeat - Each death makes you stronger for the next run

Quick Tips

  • ► Prioritize health upgrades early - survival is key
  • ► Don't spend all gold mid-run - escape with some for upgrades
  • ► Watch enemy attack patterns - timing matters
  • ► Save rare items for deeper floors
  • ► Focus on one upgrade tree at a time
  • ► Higher loops = exponentially better rewards
